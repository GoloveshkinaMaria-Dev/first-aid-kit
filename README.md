# 🏥 First Aid Kit — веб-сервис управления домашней аптечкой

Веб-приложение на Django, которое помогает следить за сроком годности лекарств и не забывать о приёме таблеток.
Публичный TODO обновляется по мере внесения изменений в проект.
## 📋 Возможности

- 💊 **Учёт лекарств** — добавление таблеток с датой покупки, сроком годности и периодичностью приёма
- 📧 **Email-напоминания** — уведомления о предполагаемой дате повторной покупки препарата
- 📅 **Календарь-таймер** — график приёма лекарств с визуализацией
- ✅ **Чеклист приёма** — отметки о принятых/пропущенных дозах
- 👤 **Пользовательские профили** — у каждого своя аптечка

## 🛠️ Технологии

- **Backend:** Python 3.x, Django
- **База данных:** PostgreSQL
- **Frontend:** Django Templates, HTML/CSS, JavaScript
- **Планировщик задач:** Celery + Redis
